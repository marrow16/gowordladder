# GoWordLadder

GoLang [Word Ladder](https://en.wikipedia.org/wiki/Word_ladder) solver, generator & analysis.

Run CLI interactively:
```
go run ./cmd/cli
```

Run TUI (terminal UI):
```
go run ./cmd/tui
```
